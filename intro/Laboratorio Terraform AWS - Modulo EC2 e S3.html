Laboratorio Terraform: Modulo Custom

marblemind.eu

Obiettivo del Laboratorio

In questo laboratorio impareremo a incapsulare risorse AWS in un Modulo Terraform riutilizzabile. Invece di definire risorse sparse, creeremo un pacchetto unico che proviziona una macchina virtuale (EC2) e un bucket di storage (S3) associato.

Prerequisiti: Terraform installato, AWS CLI configurata con le credenziali, un editor di testo (VS Code).

Step 1: Struttura del Progetto

Per mantenere il codice pulito, separeremo la logica del modulo dall'implementazione principale. Crea la seguente struttura di cartelle:

terraform-lab/ ├── main.tf # File principale (Root Module) ├── outputs.tf # Output principali └── modules/ └── compute_storage/ # Il nostro modulo custom ├── main.tf # Risorse del modulo (EC2 + S3) ├── variables.tf # Input del modulo └── outputs.tf # Output del modulo

Step 2: Creazione del Modulo

Definiamo le risorse all'interno del modulo. Questo codice andrà nella cartella modules/compute_storage.

modules/compute_storage/variables.tf 
variable "environment" {
  description = "L'ambiente di deploy (es. dev, prod)"
  type        = string
  default     = "dev"
}

variable "instance_type" {
  description = "Tipo di istanza EC2"
  type        = string
  default     = "t2.micro"
}

variable "bucket_prefix" {
  description = "Prefisso per il nome del bucket S3"
  type        = string
}
modules/compute_storage/main.tf 
# Generiamo un ID casuale per rendere unico il nome del bucket
resource "random_id" "bucket_suffix" {
  byte_length = 4
}

# Creazione Bucket S3
resource "aws_s3_bucket" "lab_bucket" {
  bucket = "${var.bucket_prefix}-${var.environment}-${random_id.bucket_suffix.hex}"
  
  tags = {
    Name        = "Lab Bucket"
    Environment = var.environment
    CreatedBy   = "Marblemind Lab"
  }
}

# Recuperiamo l'ultima AMI Amazon Linux 2
data "aws_ami" "amazon_linux" {
  most_recent = true
  owners      = ["amazon"]

  filter {
    name   = "name"
    values = ["amzn2-ami-hvm-*-x86_64-gp2"]
  }
}

# Creazione Istanza EC2
resource "aws_instance" "lab_server" {
  ami           = data.aws_ami.amazon_linux.id
  instance_type = var.instance_type

  tags = {
    Name        = "Lab-Server-${var.environment}"
    Environment = var.environment
  }
}
modules/compute_storage/outputs.tf 
output "instance_id" {
  value = aws_instance.lab_server.id
}

output "bucket_name" {
  value = aws_s3_bucket.lab_bucket.id
}

Step 3: Utilizzo del Modulo (Root)

Ora torniamo nella cartella radice terraform-lab/ e chiamiamo il modulo che abbiamo appena creato.

main.tf (Root) 
provider "aws" {
  region = "us-east-1" # O la tua regione preferita
}

# Chiamata al modulo
module "my_lab_infrastructure" {
  source = "./modules/compute_storage"

  # Passaggio delle variabili al modulo
  environment   = "training"
  bucket_prefix = "marblemind-lab"
  instance_type = "t2.micro"
}
outputs.tf (Root) 
output "final_instance_id" {
  description = "ID dell'istanza creata dal modulo"
  value       = module.my_lab_infrastructure.instance_id
}

output "final_bucket_name" {
  description = "Nome del bucket creato dal modulo"
  value       = module.my_lab_infrastructure.bucket_name
}

Step 4: Esecuzione

Apri il terminale nella cartella radice ed esegui i comandi:

$ terraform init

# Inizializza Terraform e scarica il provider AWS.

$ terraform plan

# Mostra l'anteprima delle risorse che verranno create (2 risorse + random_id).

$ terraform apply -auto-approve

# Applica le modifiche e crea l'infrastruttura.

Step 5: Pulizia

Per evitare costi aggiuntivi su AWS, ricorda di distruggere le risorse alla fine del laboratorio:

$ terraform destroy -auto-approve
