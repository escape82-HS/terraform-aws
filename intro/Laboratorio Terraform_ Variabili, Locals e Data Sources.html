Laboratorio Terraform Avanzato

Variabili, Locals e Data Sources

Visita www.marblemind.eu

Cosa imparerai

In questo laboratorio abbandoneremo i valori "hardcoded". Imparerai a:

  • Utilizzare Input Variables per parametrizzare la configurazione.
  • Sfruttare Locals per trasformare dati e semplificare la logica interna.
  • Usare Data Sources per trovare automaticamente il VPC di default e le sue Subnet, senza dover copiare/incollare ID.
1

Definizione delle Variabili (Input)

Creiamo il file variables.tf. Queste sono le "manopole" che l'utente può girare per configurare il deployment.

variables.tf
variable "aws_region" {
  description = "La regione AWS dove deployare le risorse"
  type        = string
  default     = "us-east-1"
}

variable "project_name" {
  description = "Nome del progetto per i tag"
  type        = string
  default     = "marblemind-lab"
}

variable "environment" {
  description = "Ambiente (dev, staging, prod)"
  type        = string
  validation {
    condition     = contains(["dev", "staging", "prod"], var.environment)
    error_message = "L'ambiente deve essere uno tra: dev, staging, prod."
  }
}

variable "instance_size" {
  description = "Mappa delle dimensioni istanza per ambiente"
  type        = map(string)
  default = {
    dev     = "t2.micro"
    staging = "t3.micro"
    prod    = "t3.medium"
  }
}
2

Data Sources (Lettura Dinamica)

Invece di scrivere `vpc-123456`, chiediamo ad AWS: "Dammi il VPC di default". Poi chiediamo: "Dammi le subnet di quel VPC".

data.tf (o parte di main.tf)
# 1. Trova il VPC di Default
data "aws_vpc" "default" {
  default = true
}

# 2. Trova gli ID delle Subnet associate a quel VPC
data "aws_subnets" "default_subnets" {
  filter {
    name   = "vpc-id"
    values = [data.aws_vpc.default.id]
  }
}

# 3. Trova l'ultima AMI Amazon Linux 2023
data "aws_ami" "amazon_linux_2023" {
  most_recent = true
  owners      = ["amazon"]

  filter {
    name   = "name"
    values = ["al2023-ami-2023.*-x86_64"]
  }
}
3

Locals e Risorse (Logica & Deploy)

Qui usiamo locals per calcolare valori intermedi (come i tag comuni) e selezionare la subnet giusta. Poi creiamo l'istanza.

main.tf
provider "aws" {
  region = var.aws_region
}

# LOCALS: Logica interna e trasformazione dati
locals {
  # Creiamo un set standard di tag da applicare ovunque
  common_tags = {
    Project     = var.project_name
    Environment = var.environment
    Owner       = "Marblemind Team"
    ManagedBy   = "Terraform"
  }

  # Selezioniamo dinamicamente la prima subnet disponibile dalla lista ottenuta via Data Source
  selected_subnet_id = data.aws_subnets.default_subnets.ids[0]

  # Nome composto per l'istanza
  instance_name = "${var.project_name}-server-${var.environment}"
}

# RESOURCE: Creazione EC2
resource "aws_instance" "web_server" {
  # Usa l'AMI trovata dinamicamente
  ami           = data.aws_ami.amazon_linux_2023.id
  
  # Seleziona la dimensione in base all'ambiente (lookup nella mappa)
  instance_type = var.instance_size[var.environment]
  
  # Usa la subnet trovata dinamicamente
  subnet_id     = local.selected_subnet_id

  # Uniamo i tag comuni con il nome specifico
  tags = merge(
    local.common_tags,
    {
      Name = local.instance_name
    }
  )
}
4

Outputs

Restituiamo le informazioni utili all'utente.

outputs.tf
output "ec2_public_ip" {
  description = "Indirizzo IP pubblico dell'istanza"
  value       = aws_instance.web_server.public_ip
}

output "vpc_info" {
  description = "Info sul VPC utilizzato (scoperto dinamicamente)"
  value       = "Deployato nel VPC: ${data.aws_vpc.default.id} (CIDR: ${data.aws_vpc.default.cidr_block})"
}

output "environment_type" {
  value = "Stai usando l'ambiente: ${var.environment}"
}

Come Eseguire il Laboratorio

1. Crea un file terraform.tfvars per definire le tue variabili:

environment = "dev"
project_name = "marblemind-demo"

2. Inizializza e applica:

terraform init
terraform apply

3. Prova a cambiare l'ambiente:

Modifica terraform.tfvars impostando environment = "prod" e ri-esegui apply. Noterai che l'istanza cambierà tipo (da t2.micro a t3.medium) grazie alla mappa nelle variabili.
